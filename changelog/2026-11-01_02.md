# The Agent-Harnesses Profiles Carry the Kit's Metadata Template

## Why Care?

[[2026-11-01_01]] made `agent-harnesses/context-v/` an Open Knowledge Format bundle. This pass brings the same docs up to the Context Vigilance Kit's frontmatter template, so a reader or a workflow dashboard can sort the profiles, credit them, and see at a glance that they are reference material rather than work in flight.

## What's New?

- **A status on every profile.** All ten say `Reference`: each describes an upstream tool as it was studied at its pin.
- **Titles on the profiles**, taken from each one's heading (`Aider — Profile`, and so on).
- **Authors on the profiles**, from their only human committer.
- **A `date_modified` on all 11 docs**, from each file's last commit before this sweep.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]], and the status vocabulary in the context-vigilance skill's `status-discipline.md`.
- Every edit was made by hand, frontmatter only. No body line changed, no existing date moved, and today's date was written into no existing doc.
- The inquiry doc keeps its `Draft` status and its `semantic_version:` key, a permanent alias. Its `Agent-Harnesses` tag stays: it names the study's topic.
